# PageTurner: Online Book Store

A responsive online book store front-end built with plain HTML, CSS and JavaScript. No frameworks or build tools needed.

## Features
- Book catalogue with 12 sample titles
- Live search by title or author
- Category filters (Fiction, Technology, Self-Help, History)
- Add to cart with a live cart counter
- Responsive layout for mobile, tablet and desktop

## Project Structure
```
online-book-store/
  index.html   page structure
  style.css    styling and responsive layout
  script.js    catalogue data, search, filters, cart
  README.md
```

## How to Run
Open `index.html` in any browser.

## Host Free on GitHub Pages
1. Open the repository **Settings** → **Pages**.
2. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
3. Your site goes live at `https://amanyadav991980.github.io/<repo-name>/`.
